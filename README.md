## Objetivo

Diseñar, implementar, operar y asegurar una red empresarial jerárquica de cinco capas con mecanismos de redundancia y failover mediante VRRP, OSPF y BGP multi-homing.

## Fases

- F0 — Diseño y gestión de cambio
- F1 — Topología, hardening y backup
- F2 — VRRP y OSPF
- F3 — BGP y firewall
- F4 — Drills y monitoreo
- F5 — Memoria y defensa
